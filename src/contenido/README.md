# PRETSO — Precios del Teatro del Siglo de Oro

> Texto provisional. Laura Paz Rescala redactará la versión definitiva.

## Qué es

PRETSO es una base de datos para el estudio de las dinámicas económicas del teatro comercial en los territorios hispanos (siglos XVI-XVII). Es un resultado del proyecto THIS (Theater in Imperial Spain), financiado por la Unión Europea (MSCA, acuerdo n.º 101150056) y desarrollado en la Università Ca' Foscari Venezia.

## Quién puede usarla

Para consultar la base de datos hay que iniciar sesión con una cuenta autorizada por el equipo del proyecto. Solo la administración puede editar los datos.

## Secciones

- Búsqueda general: consulta guiada en toda la base de datos.
- Manejo de caja: transacciones de las cajas de las compañías.
- Remuneraciones: salarios y pagos.
- Corpus Christi: registros de las fiestas del Corpus Christi.
- Compañías: índice de compañías teatrales.
- Bibliografía: fuentes y referencias.
- Documentos: documentos de archivo asociados a los registros.
- Identificación de indicadores: criterios usados para identificar los indicadores.
